🎯 1. Introduction to Benchmark Testing

Benchmark testing is a performance measurement methodology that evaluates the execution time, memory usage, and computational efficiency of software components under controlled conditions. Unlike unit tests that verify correctness, benchmark tests measure how fast and how efficiently code executes.

Key Principles:
  • Repeatability: Tests must produce consistent results across multiple runs
  • Isolation: Each benchmark should test a single operation or algorithm
  • Statistical Significance: Multiple iterations with statistical analysis
  • Real-world Scenarios: Test data sizes and patterns relevant to actual usage

🔬 How Benchmark Testing Works

The benchmark process follows this methodology:

  1. Setup Phase: Initialize test data and system state
  2. Warm-up Phase: Execute operations to stabilize CPU caches and branch predictors
  3. Measurement Phase: Execute operations while measuring time/resources
  4. Statistical Analysis: Calculate mean, median, standard deviation, and percentiles
  5. Reporting Phase: Generate performance reports and comparisons

🔍 2. Why Benchmark Testing Matters for Cryptographic Libraries

Critical Performance Aspects in Cryptography:

  • Throughput: Operations per second for high-volume scenarios
  • Latency: Response time for real-time applications
  • Constant-time Operations: Preventing timing attacks
  • Memory Efficiency: Cache performance and memory footprint
  • Scalability: Performance with different data sizes

🎯 Specific Benefits for Integer.hpp

  • Bit Manipulation Optimization: Verify that bit operations are compiler-optimized
  • Cache Performance: Ensure operations fit within CPU cache lines
  • Branch Prediction: Measure impact of conditional operations
  • SIMD Utilization: Detect automatic vectorization opportunities
  • Type Performance Comparison: Compare uint8/16/32/64 performance characteristics

/** * @brief Base class for performance benchmark tests * * Extends the existing Test framework with benchmark-specific functionality * including statistical timing, warm-up phases, and performance reporting. */ class BenchmarkTest : public UnitTests::Test { protected: size_t iterations = 1000; ///< Number of benchmark iterations size_t warmup_iterations = 100; ///< Number of warm-up iterations PerformanceMetrics metrics; ///< Statistical performance data public: /** * @brief Set the number of benchmark iterations * @param iter Number of iterations to execute */ void setIterations(size_t iter) { iterations = iter; } /** * @brief Set the number of warm-up iterations * @param warmup Number of warm-up iterations */ void setWarmupIterations(size_t warmup) { warmup_iterations = warmup; } /** * @brief Measure performance of a benchmark function * @param name Descriptive name for the benchmark * @param func Function to benchmark */ template<typename Func> void measurePerformance(const std::string& name, Func&& func) { // Warm-up phase for (size_t i = 0; i < warmup_iterations; ++i) { func(); } // Measurement phase std::vector<double> timings; timings.reserve(iterations); for (size_t i = 0; i < iterations; ++i) { auto start = HighResClock::now(); func(); auto end = HighResClock::now(); auto duration_ns = duration_cast<nanoseconds>(end - start).count(); timings.push_back(static_cast<double>(duration_ns)); } metrics.analyzeTiming(name, timings); } /** * @brief Measure performance with separate setup function * @param name Descriptive name for the benchmark * @param setup_func Setup function called before each iteration * @param benchmark_func Function to benchmark */ template<typename SetupFunc, typename BenchmarkFunc> void measurePerformanceWithSetup(const std::string& name, SetupFunc&& setup_func, BenchmarkFunc&& benchmark_func) { // Warm-up phase for (size_t i = 0; i < warmup_iterations; ++i) { setup_func(); benchmark_func(); } // Measurement phase std::vector<double> timings; timings.reserve(iterations); for (size_t i = 0; i < iterations; ++i) { setup_func(); auto start = HighResClock::now(); benchmark_func(); auto end = HighResClock::now(); auto duration_ns = duration_cast<nanoseconds>(end - start).count(); timings.push_back(static_cast<double>(duration_ns)); } metrics.analyzeTiming(name, timings); #pragma once #include <vector> #include <string> #include <map> #include <algorithm> #include <numeric> #include <cmath> #include <iostream> #include <iomanip> namespace BenchmarkTests { /** * @brief Statistical analysis and reporting for performance metrics * * Provides comprehensive statistical analysis of benchmark timing data * including mean, median, standard deviation, percentiles, and outlier detection. */ class PerformanceMetrics { private: struct BenchmarkResult { std::string name; double mean_ns; ///< Mean execution time in nanoseconds double median_ns; ///< Median execution time in nanoseconds double std_dev_ns; ///< Standard deviation in nanoseconds double min_ns; ///< Minimum execution time double max_ns; ///< Maximum execution time double p95_ns; ///< 95th percentile double p99_ns; ///< 99th percentile size_t sample_count; ///< Number of samples double ops_per_second; ///< Operations per second }; std::vector<BenchmarkResult> results; public: /** * @brief Analyze timing data and compute statistical metrics * @param name Benchmark name * @param timings Vector of timing measurements in nanoseconds */ void analyzeTiming(const std::string& name, std::vector<double> timings) { if (timings.empty()) return; // Sort for percentile calculations std::sort(timings.begin(), timings.end()); BenchmarkResult result; result.name = name; result.sample_count = timings.size(); // Basic statistics result.min_ns = timings.front(); result.max_ns = timings.back(); result.mean_ns = std::accumulate(timings.begin(), timings.end(), 0.0) / timings.size(); // Median size_t mid = timings.size() / 2; if (timings.size() % 2 == 0) { result.median_ns = (timings[mid - 1] + timings[mid]) / 2.0; } else { result.median_ns = timings[mid]; } // Standard deviation double variance = 0.0; for (const auto& time : timings) { variance += std::pow(time - result.mean_ns, 2); } result.std_dev_ns = std::sqrt(variance / timings.size()); // Percentiles result.p95_ns = timings[static_cast<size_t>(0.95 * timings.size())]; result.p99_ns = timings[static_cast<size_t>(0.99 * timings.size())]; // Operations per second (based on median) result.ops_per_second = 1e9 / result.median_ns; results.push_back(result); } /** * @brief Print comprehensive performance report */ void printReport() const { if (results.empty()) return; std::cout << "\n" << std::string(100, '=') << "\n"; std::cout << "🚀 PERFORMANCE BENCHMARK REPORT\n"; std::cout << std::string(100, '=') << "\n\n"; // Table header std::cout << std::left << std::setw(35) << "Benchmark" << std::right << std::setw(12) << "Median (ns)" << std::setw(12) << "Mean (ns)" << std::setw(12) << "Std Dev" << std::setw(15) << "Ops/sec" << std::setw(12) << "P95 (ns)" << std::setw(12) << "P99 (ns)" << "\n"; std::cout << std::string(100, '-') << "\n"; // Results table for (const auto& result : results) { std::cout << std::left << std::setw(35) << truncateString(result.name, 34) << std::right << std::setw(12) << std::fixed << std::setprecision(2) << result.median_ns << std::setw(12) << std::fixed << std::setprecision(2) << result.mean_ns << std::setw(12) << std::fixed << std::setprecision(2) << result.std_dev_ns << std::setw(15) << std::fixed << std::setprecision(0) << result.ops_per_second << std::setw(12) << std::fixed << std::setprecision(2) << result.p95_ns << std::setw(12) << std::fixed << std::setprecision(2) << result.p99_ns << "\n"; } std::cout << "\n"; printSummaryStatistics(); } /** * @brief Get results for external analysis * @return Vector of benchmark results */ const std::vector<BenchmarkResult>& getResults() const { return results; } private: std::string truncateString(const std::string& str, size_t max_length) const { if (str.length() <= max_length) return str; return str.substr(0, max_length - 3) + "..."; } void printSummaryStatistics() const { if (results.empty()) return; // Find fastest and slowest operations auto fastest = std::min_element(results.begin(), results.end(), [](const auto& a, const auto& b) { return a.median_ns < b.median_ns; }); auto slowest = std::max_element(results.begin(), results.end(), [](const auto& a, const auto& b) { return a.median_ns < b.median_ns; }); std::cout << "📊 SUMMARY STATISTICS:\n"; std::cout << " Fastest operation: " << fastest->name << " (" << std::fixed << std::setprecision(2) << fastest->median_ns << " ns)\n"; std::cout << " Slowest operation: " << slowest->name << " (" << std::fixed << std::setprecision(2) << slowest->median_ns << " ns)\n"; std::cout << " Performance ratio: " << std::fixed << std::setprecision(1) << (slowest->median_ns / fastest->median_ns) << "x\n"; std::cout << " Total benchmarks: " << results.size() << "\n\n"; } }; }
