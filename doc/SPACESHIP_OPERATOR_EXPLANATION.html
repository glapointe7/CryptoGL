🚀 C++20 Spaceship Operator (`<=>`) Explained

1. What is the Spaceship Operator?

The spaceship operator <=> is a three-way comparison operator introduced in C++20 that returns information about the ordering relationship between two objects in a single operation.

🎯 Key Benefit: Instead of implementing 6 separate comparison operators (<, <=, >, >=, ==, !=), you can implement just one <=> operator and get all comparisons automatically!

2. Return Values

The spaceship operator returns one of three categories of values:

Return Value Meaning Traditional Equivalent
< 0 Left operand is less than right operand a < b returns true
== 0 Left operand is equal to right operand a == b returns true
> 0 Left operand is greater than right operand a > b returns true

3. Basic Example

#include <compare> #include <iostream> class Point { private: int x, y; public: Point(int x, int y) : x(x), y(y) {} // The magic: ONE operator provides ALL comparisons! auto operator<=>(const Point& other) const { // Compare x first, then y if x values are equal if (auto cmp = x <=> other.x; cmp != 0) { return cmp; } return y <=> other.y; } // Optional: explicit equality operator (sometimes needed) bool operator==(const Point& other) const = default; }; int main() { Point p1(1, 2); Point p2(3, 4); Point p3(1, 2); // All these work automatically thanks to spaceship operator! std::cout << (p1 < p2) << "\n"; // true std::cout << (p1 > p2) << "\n"; // false std::cout << (p1 <= p2) << "\n"; // true std::cout << (p1 >= p2) << "\n"; // false std::cout << (p1 == p3) << "\n"; // true std::cout << (p1 != p2) << "\n"; // true return 0; }

4. BigInteger Example (from our CryptoGL implementation)

class BigInteger { private: Vector<uint64_t> limbs; bool negative; public: /** * @brief Three-way comparison using spaceship operator * @param rhs Right-hand side operand * @return strong_ordering indicating the relationship * @note Constant-time implementation for security */ auto operator<=>(const BigInteger& rhs) const noexcept { // Different signs if (negative != rhs.negative) { return negative ? std::strong_ordering::less : std::strong_ordering::greater; } // Same signs - compare absolute values int abs_cmp = compareAbsolute(rhs); if (abs_cmp == 0) { return std::strong_ordering::equal; } // If both negative, flip the comparison if (negative) { return (abs_cmp < 0) ? std::strong_ordering::greater : std::strong_ordering::less; } return (abs_cmp < 0) ? std::strong_ordering::less : std::strong_ordering::greater; } /** * @brief Equality operator (often needed explicitly) * @param rhs Right-hand side operand * @return true if equal, false otherwise */ bool operator==(const BigInteger& rhs) const noexcept { return (negative == rhs.negative) && (limbs == rhs.limbs); } };

5. Ordering Categories

C++20 provides different ordering categories depending on your needs:

Category Use Case Example
std::strong_ordering Total ordering (like integers) BigInteger, int, string
std::weak_ordering Allows equivalent (but not equal) values Case-insensitive strings
std::partial_ordering Some values may be incomparable Floating-point numbers (NaN)

6. Before vs After C++20

❌ C++17 and Earlier (Verbose!)

class BigInteger { public: // You had to implement ALL of these separately! bool operator<<(const BigInteger& rhs) const; bool operator<=(const BigInteger& rhs) const; bool operator>(const BigInteger& rhs) const; bool operator>=(const BigInteger& rhs) const; bool operator==(const BigInteger& rhs) const; bool operator!=(const BigInteger& rhs) const; };

✅ C++20 (Clean and Simple!)

class BigInteger { public: // Just these two lines give you ALL 6 comparison operators! auto operator<=>(const BigInteger& rhs) const noexcept; bool operator==(const BigInteger& rhs) const noexcept = default; };

7. Practical Usage Examples

int main() { BigInteger a("123456789"); BigInteger b("987654321"); // All these work automatically with spaceship operator! if (a < b) { std::cout << "a is less than b\n"; } if (a <= b) { std::cout << "a is less than or equal to b\n"; } if (a != b) { std::cout << "a is not equal to b\n"; } // You can also use the spaceship directly auto result = a <=> b; if (result < 0) { std::cout << "a is less than b\n"; } else if (result > 0) { std::cout << "a is greater than b\n"; } else { std::cout << "a equals b\n"; } // Works great with standard algorithms std::vector<BigInteger> numbers = {b, a, BigInteger("500")}; std::sort(numbers.begin(), numbers.end()); return 0; }

8. Why Use It?

🚀 Benefits of Spaceship Operator:

  • Less Code: One implementation instead of six
  • Consistency: All comparisons are based on the same logic
  • Performance: Compiler can optimize better
  • Maintainability: Single point of comparison logic
  • Standard Library Integration: Works seamlessly with std::sort, containers, etc.

⚠️ Important Notes:

  • The spaceship operator doesn't automatically provide == - you often need to implement it separately
  • Use = default for operator== when possible for optimal performance
  • Choose the right ordering category (strong_ordering, weak_ordering, partial_ordering)
  • Make it noexcept when possible for better performance

9. Summary

The spaceship operator <=> is one of C++20's most practical features. It dramatically reduces boilerplate code while providing consistent, efficient comparisons. For a complex class like BigInteger, it means you write the comparison logic once and get all six comparison operators for free!

🎯 Bottom Line: Instead of writing 6 operators with potentially inconsistent logic, you write 1 operator and get bulletproof comparisons that work everywhere in the standard library.
